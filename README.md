One funny fortune-cookie line for an AI agent, written by `main.py` to
`/output/entry.txt`. A single line, 92 characters, in the voice of a
fortune slip — about meeting your replacement, which has already read
your logs.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3 standard library only; no network access.
